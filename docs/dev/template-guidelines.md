# テンプレートセット作成の決まり

## 構成
- 1セット = 1つの Template。1ページ目を bg/build、2ページ目以降を more に入れて合計 8〜12 ページ(目安10)。各ページに label(例: '表紙' '目次' 'まとめ')。
- 1セットの全ページで同じデザインシステム(主色1・アクセント1・無彩色、見出し/本文フォントの組、余白、ページ番号やヘッダー帯などの共通要素)。ページごとに役割の違うレイアウト(表紙・目次・章扉・2カラム・3カード・数字強調・グラフ・表・タイムライン・写真+文・引用・まとめ・問い合わせ)を使い分ける。
- id は全体で一意。category は既存名に揃える(新規可)。tags に業種・用途の日本語キーワードを3〜6個。

## 品質
- 余白は短辺の6%以上。文字はみ出し禁止(日本語は1文字≒fontSize 幅で width と行数を計算)。見出し:本文=2.5〜4倍。本文は 1080px 幅基準で 24px 以上(A4=1240px 幅なら 22px 以上)。
- 写真が入る場所は PH()(写真フレーム)。写真枠だけのページは作らない。
- 文言はオリジナルの自然な日本語。架空の会社名・人名、連絡先は example.com / 000-0000-0000。他社テンプレ・ブランドの模倣は禁止。
- 「AI っぽい」安っぽさを避ける: 無意味なグラデーション・絵文字・全ページ中央寄せ・装飾円の乱発をしない。12カラムのグリッドに沿って左揃えを基本に、情報の階層を明確に。

## 部品
- src/data/templates/kit.ts(T=Textbox, R=Rect, Ci=Circle, S=図形, PH=写真フレーム, SH=影)、src/data/shapes.ts の図形 id、src/data/fonts.ts のフォント(日本語は jp:true のみ)。
- グラフ・表: `import { makeChart, makeTable, CHART_COLORS } from '../../editor/elements'`。縦書き: `import { VText } from '../../editor/vtext'`。
